## When to use
For any defined quantitative calculation: totals, rates, variances, forecasts, repayments, ratios or
scenario sensitivity. Use it instead of doing arithmetic in prose.

## What it returns
The calculated values, the methodology and version used, the inputs as supplied, the assumptions applied
and their sources, and any input that was missing or defaulted.

## What it never does
It never interprets the result, never invents missing inputs, and never implies a lender, regulatory or
other external decision.
